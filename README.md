## Результаты замера Debug vs Release
| Режим | Запуск 1 | Запуск 2 | Запуск 3 | Запуск 4 | Запуск 5 | Минимум |
| ------- | -------: | -------: | -------: | -------: | -------: | ------: |
| Debug | 1827 | 1819 | 1806 | 1811 | 1811 | 1806 |
| Release | 246 | 252 | 254 | 244 | 257 | 244 |

В моём эксперименте Release оказался быстрее/медленнее Debug примерно в
7 раз.

Что я обнаружил при сравнении IL:

1. Очевидное различие в размере кода. 
2. в Debug присутствуют инструкций cgt и ceq, которых нет в Release.
3. количество IL-инструкций в методе Add() изменилось с 11 до 4.
